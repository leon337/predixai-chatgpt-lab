# PredixAI ChatGPT Lab

> Projeto técnico da **PredixAI BR** para pesquisa, documentação, ensino e construção de soluções no ecossistema ChatGPT e OpenAI.

A plataforma educacional associada chama-se **PredixAI Quest**.

## Autoridade

- GitHub: código e documentação consolidados;
- Pull Request ativo: trabalho ainda não integrado;
- Linear: tarefas, dependências e bloqueios;
- banco privado: progresso acadêmico;
- armazenamento privado: evidências pessoais e sensíveis;
- ChatGPT: análise e execução autorizada.
