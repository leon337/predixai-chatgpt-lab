# Pacote de evidência — template privado

> Este arquivo é um modelo. Respostas reais, prints, notas e identificadores pessoais não devem ser publicados no GitHub.

```yaml
id: EVD-XXXX
attempt_id: ATT-XXXX
mission_id: MSN-XXXX
mission_version: 1.0.0
classification: PRIVATE
status: DECLARED
storage_ref: PRIVATE_STORAGE_ONLY
redacted: false
created_at: YYYY-MM-DDTHH:MM:SSZ
```

## 1. Resultado produzido

Descrever o artefato ou resultado sem copiar credenciais, dados pessoais ou conteúdo proibido.

## 2. Procedimento executado

Registrar as etapas realmente realizadas e distinguir execução prática de simulação ou análise documental.

## 3. Explicação com palavras próprias

Explicar o conceito, as decisões tomadas, limitações e o que seria feito de maneira diferente.

## 4. Verificação

- [ ] o resultado foi realmente produzido;
- [ ] a evidência corresponde à versão da missão;
- [ ] não há segredo ou credencial;
- [ ] não há dado pessoal desnecessário;
- [ ] a classificação foi conferida;
- [ ] a evidência está em armazenamento privado;
- [ ] a versão pública, quando existir, foi sanitizada e aprovada.

## 5. Declaração de segurança

```text
SECRETS_INCLUDED=NO
PERSONAL_DATA_INCLUDED=NO
FABRICATED_RESULT=NO
PUBLICATION_AUTHORIZED=NO_BY_DEFAULT
```
