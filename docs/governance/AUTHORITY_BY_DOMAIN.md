# Autoridade por domínio

Não existe uma ordem global que resolva todas as divergências.

| Campo ou domínio | Fonte governante |
|---|---|
| conteúdo integrado | GitHub `main` |
| conteúdo não integrado | PR e branch ativos |
| tarefa, prioridade, dependência e bloqueio | Linear |
| transição operacional | `PROJECT_RUNTIME_STATE.yaml` |
| explicação humana do estado | `PROJECT_STATE.md` |
| decisão vigente | arquivo DEC ativo e registro central |
| progresso do aluno | banco acadêmico privado |
| arquivo de evidência | armazenamento privado |
| especificação oficial OpenAI | documentação oficial externa |
| conversa corrente | contexto temporário |

Divergências são declaradas por campo. Histórico não governa o presente; correções usam nova versão, adendo ou evento compensatório.
