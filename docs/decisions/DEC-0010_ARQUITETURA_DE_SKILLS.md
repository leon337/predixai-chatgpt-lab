# DEC-0010 — Arquitetura de Skills

```yaml
id: DEC-0010
status: APPROVED
version: 1.0.0
```

Uma Skill possui núcleo portátil e adaptadores por superfície.

Componentes: manifesto, instruções, entradas, saídas, exemplos, recursos, testes, segurança, dependências e adaptadores.

Estados: `EXPERIMENTAL`, `PILOT`, `VALIDATED`, `STABLE`, `DEPRECATED`, `ARCHIVED`.

`STABLE` exige três execuções variadas, revisão de segurança, consistência documentada e validação em cada superfície declarada. No piloto V0.1, a entrega esperada é uma candidata a Skill, não uma Skill estável.
