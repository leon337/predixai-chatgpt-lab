# Glossário

- **Trilha:** segmento principal de formação.
- **Campanha:** grande objetivo de aprendizagem.
- **Mundo:** área temática.
- **Módulo:** conjunto de competências relacionadas.
- **Missão:** unidade prática e avaliável.
- **Etapa:** passo interno de uma missão.
- **Evidência:** prova verificável produzida pelo aluno.
- **Domínio:** aprovação prática com requisitos eliminatórios cumpridos.
- **Retenção:** confirmação posterior de que o domínio permaneceu.
- **Remediação:** atividade corretiva após uma lacuna identificada.
- **Prompt:** componente versionado que orienta uma execução.
- **Skill:** pacote reutilizável com instruções, recursos, testes, permissões e adaptadores.
- **Superfície:** ambiente de execução, como ChatGPT, Codex, GitHub ou API.
- **Fonte de verdade:** sistema autorizado para governar um domínio específico.
- **Transição:** mudança operacional idempotente identificada e auditável.
- **Baseline:** conjunto versionado e revisado usado como referência estável.
